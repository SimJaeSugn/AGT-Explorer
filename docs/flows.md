## 4. 반응형 / 레이아웃 규칙

- 창 폭이 좁아지면: 사이드바 자동 접힘 가능, 4분할은 최소 폭 미달 시 안내.
- 패널은 최소 가용 폭을 가지며, 미달 시 분할 추가를 막거나 경고.
- **분할선 드래그로 비율 조절(S, features §H3)**: 2분할=1축·4분할=가로/세로 2축. 최소 폭/높이 제약 이하로는 줄지 않으며, 분할선 더블클릭 시 균등 복귀. **조정 비율은 탭/레이아웃별로 세션 영속**(재시작 후 유지). MVP는 균등 분할.
- **사이드바 토글(S, features §H2)**: `Ctrl+B`/아이콘바 버튼으로 표시·숨김 전환, 숨김 시 패널 영역이 그 공간으로 확장. 토글 상태는 세션 영속.
- 미리보기 패널(S)은 패널 영역 우측 또는 하단에 토글로 부착. **(J6 ✅) 미리보기-본문 분할선 드래그로 폭 조절·세션 영속(`ui.previewWidth`·H3 메커니즘 재사용), (J5 ✅) 상하 2단(정보+뷰어: 이미지·텍스트·코드강조·마크다운).**
- **패널 실시간 갱신(S, features §J2 ✅)**: 각 패널이 자기 폴더를 워처로 감시해 디스크 변경을 자동 반영(`fs:watch:*`·디바운스·정렬/필터·선택/스크롤 보존·권한/삭제/네트워크 예외 격리·`softRefresh`). **UNC + 매핑 네트워크 드라이브(`X:\`) 폴링 폴백 ✅**(`GetDriveType` 연동: `os/driveType.ts` PowerShell CIM `DriveType=4`·`paths.isNetworkDriveRoot`). `subst`·일부 클라우드(`DriveType≠4`)만 미포함 한계.
- **사용량 대시보드(S, features §I1 ✅)** 는 메인 화면 위 모달 오버레이로 표시(부착형 아님·`DashboardModal`). 실행 시 자동 팝업은 설정 토글(기본 켜짐)로 제어하며, 모달 동안에도 백그라운드 스캔(`scanWorker`)은 비차단.
