## 1. 정보 구조 (IA) — 메인 화면 구성

```
┌────────────────────────────────────────────────────────────────────────┐
│  [탭바]  탭1 │ 탭2 │ 탭3 │ +            (현재 탭 = 하나의 레이아웃)        │
├────────────────────────────────────────────────────────────────────────┤
│ [툴바]  ← → ↑ │ 주소 표시줄(브레드크럼/편집)          │ 검색 [Ctrl+F]     │
├──────────┬──────────────────────────────────────────┬──────────────────┤
│          │  ┌────────────────────┬────────────────┐  │ [미리보기 패널 S] │
│ [사이드바]│  │  패널 A (활성)      │  패널 B        │  │  Ctrl+P 토글      │
│  즐겨찾기 │  │  ─주소표시줄/정렬헤더│ ─주소표시줄/정렬│  │  이미지축소/      │
│  최근     │  │  파일/폴더 목록     │  파일/폴더 목록 │  │  텍스트앞부분/    │
│  내 PC    │  │  (가상 스크롤)      │                │  │  메타(크기/수정일)│
│   └드라이브│  │                    │←─드래그&드롭─→ │  │  (우측 또는 하단) │
│  휴지통   │  └────────────────────┴────────────────┘  │                  │
│          │  (단일/2분할/4분할[S] 레이아웃 전환 가능)   │                  │
├──────────┴──────────────────────────────────────────┴──────────────────┤
│ [상태바]  항목 128개 │ 3개 선택 (24.5MB) │ C:\Users\...\Downloads          │
│           └─ 작업 중에는 진행률 인디케이터 표시(대용량은 별도 진행 다이얼로그)│
└────────────────────────────────────────────────────────────────────────┘
```

### 영역 역할
| 영역 | 역할 |
|---|---|
| 탭바 | 여러 위치를 탭으로 보관·전환. 각 탭 = 독립 레이아웃 |
| 툴바 | 뒤로/앞으로/위로, 주소 표시줄, 보기/정렬/분할 컨트롤, 검색 |
| **전역 아이콘바 (S)** | 탭바 아래 4그룹(레이아웃/뷰·파일 작업·탐색·도구) 아이콘 버튼. 활성 패널 기준·키보드와 동일 commandId 수렴, 컨텍스트 비활성 시 흐림. `Ctrl+B`로 사이드바 토글 진입점 포함 (features §H1·H2) |
| 사이드바 | 트리·즐겨찾기·최근·드라이브·휴지통. **`Ctrl+B`/아이콘바 버튼으로 표시·숨김 토글(상태 세션 영속)**, 폭조절 |
| 주소 표시줄 (H5 ✅) | 브레드크럼/편집 모드. **단일 클릭 시 전체 경로 편집 모드 진입**(탐색기식, `Ctrl+L`·더블클릭 유지) → Enter 이동/Esc 취소/잘못된 경로 인라인 오류(`validateAndNavigate`) |
| 목록 아이콘 (H6 ✅) | 각 항목을 **OS 실제 파일 아이콘**으로 표시(`shell:icon`). 폴더/드라이브 아이콘·미해석 폴백, 확장자 단위 캐시·화면 진입 행만 지연 로드(가상 스크롤 정합) |
| 보기 모드 (J3 ✅) | 큰/보통/작은 아이콘(그리드)·목록·자세히 **5종** 전환(아이콘바·우클릭 "보기", `ViewMode`). 아이콘 그리드는 `shell:icon`(H6) 재사용·가상 스크롤·패널별 기억 |
| 패널 워처 (J2 ✅) | 각 패널이 자기 폴더를 감시해 디스크 변경(생성/삭제/이름변경)을 수동 새로고침 없이 자동 반영(`fs:watch:*`·`WatchService`·디바운스·정렬/필터·선택/스크롤 보존·격리·`softRefresh`). **UNC + 매핑 네트워크 드라이브(`X:\`) 폴링 폴백 ✅**(`GetDriveType` 연동: `os/driveType.ts` PowerShell CIM `DriveType=4`·`paths.isNetworkDriveRoot`). `subst`·일부 클라우드(`DriveType≠4`)만 미포함 한계 |
| 즐겨찾기 별칭 (J7 ✅) | 즐겨찾기 항목 표시 이름(별칭) 변경 가능(우클릭/`F2` 인라인 편집·`favoriteLabels`)·경로 불변·영속(없으면 basename 폴백) |
| 컨텍스트 메뉴 터미널 (H4 ✅) | 폴더 항목/패널 빈 영역 우클릭에 **"터미널 열기"** — 선택 폴더(또는 현재 경로)를 cwd로 `wt.exe` 우선·없으면 PowerShell 실행(검증 경로만, ADR-005) |
| 분할 패널 | 1~4개 패널. 각 패널이 독립 탐색 뷰. 패널 간 D&D 작업 |
| 미리보기 패널 (S) | 활성 패널 선택 항목의 미리보기. `Ctrl+P` 토글, 우측 또는 하단 부착. **(J5 ✅) 상하 2단(상단 정보 `PreviewInfoCard`+하단 확장 뷰어: 이미지·텍스트·코드 구문 강조(highlight.js)·마크다운(marked+DOMPurify))·(J6 ✅) 분할선 드래그로 폭 조절(`ui.previewWidth` 세션 영속)** |
| 사용량 대시보드 (S, I1 ✅) | 아이콘바 ④도구 그룹 아이콘 또는 **실행 시 자동 팝업**(설정 "시작 시 대시보드 표시" 기본 켜짐)으로 여는 **모달**(`DashboardModal`). 드라이브 사용량 즉시(도넛+표)·선택 폴더/드라이브 Top10 온디맨드 스캔(막대+표, 진행률·취소·비차단, `analyze:scan:*`)·인사이트. `Esc`로 닫기 (features §I1) |
| 상태바 | 항목 수, 선택 개수/용량, 활성 패널 경로, **작업 중 진행률 인디케이터** |

> **계층 관계**: 창 → 탭(N) → 탭마다 레이아웃(단일/2분할/4분할) → 패널(N) → 목록.

## 2. 핵심 플로우

### F1. 두 폴더 간 파일 이동 (대표 시나리오)
```
1. 사용자가 분할 버튼 → "좌우 2분할" 선택  (툴바·아이콘바[S, Ctrl+\] 또는 키보드)
   └─ (옵션) 아이콘바 사이드바 버튼[Ctrl+B]으로 사이드바를 접어 패널을 넓게, 분할선 드래그[S]로 비율 조정
2. 패널 A에서 출발 폴더로 이동 (사이드바/주소 표시줄)
3. 패널 B에서 도착 폴더로 이동
4. 패널 A에서 파일 다중 선택 (Ctrl/Shift)
5. 선택 항목을 패널 B로 옮김 — 두 방법 중 하나
   ├─ (마우스) 패널 B로 드래그&드롭
   │    ├─ 같은 드라이브 → 이동(기본) / 다른 드라이브 → 복사
   │    └─ Ctrl=복사강제 / Shift=이동강제 (커서로 의도 표시)
   └─ (키보드) 클립보드 `Ctrl+C`/`Ctrl+X` → 패널 B에서 `Ctrl+V`로 복사/이동
        ※ 패널 포커스 전환은 `Tab`, 새로고침은 `Ctrl+R`
        ※ [2026-06-07 제거] 구 `F5`(복사)/`F6`(이동) 단축키는 삭제됨 — 패널 간 복사/이동은 D&D·클립보드로만
6. 실행 → (충돌 시) 충돌 다이얼로그(US-2.4) → 진행률 표시 → 완료
   └─ 실패 항목 있으면 결과 요약에 실패 목록
```

### F2. 새 탭으로 자주 쓰는 경로 보관
```
Ctrl+T → 새 탭 → 사이드바 즐겨찾기 클릭 / 주소 표시줄 입력
   └─ (H5 ✅) 주소 표시줄 단일 클릭 → 전체 경로 편집 → 경로 붙여넣기/타이핑 → Enter 이동(Esc 취소)
→ 탭 제목이 폴더명으로 갱신 → Ctrl+Tab으로 탭 간 전환
```

### F6. 폴더에서 바로 터미널 열기 (H4 ✅)
```
폴더 항목 또는 패널 빈 영역 우클릭 → "터미널 열기"
→ 경로 검증(정규화·.. 차단·존재·권한, ADR-005) 통과 시
→ wt.exe 있으면 Windows Terminal / 없으면 PowerShell을 그 폴더(cwd)에서 실행
   (파일·내 PC 항목에는 비활성·미표시 / 검증 실패 시 실행 없이 사유 안내)
```

### F7. 사용량 대시보드 열기·Top10 스캔/취소 (I1 ✅ 구현 완료 — `DashboardModal`·`analyze:scan:*`·`scanEngine`; 유형별 비중 선택항 미구현·네이티브 성능 실측 런타임 스모크 권장)
```
[열기] 아이콘바 ④도구 그룹 "사용량 대시보드" 클릭  또는  프로그램 실행 시 자동 팝업
       (설정 "시작 시 대시보드 표시" 켜짐일 때만 — 기본 켜짐 / 모달 내 "다음부터 표시 안 함"으로 끄기)
→ 모달 오픈 즉시: 드라이브별 총/사용/여유 용량 = 도넛 차트 + 표 (스캔 불요)
→ [Top10] 폴더 또는 드라이브 선택 → "스캔" → 백그라운드 스캔(진행률 갱신·UI 비차단)
   ├─ 진행 중에도 모달 닫기·탐색 가능 / 새 대상 선택 시 진행 스캔 취소·교체
   ├─ 취소 버튼 → 즉시 중단(부분 집계 반영 또는 직전 결과 유지·사유 안내)
   ├─ 권한 없는 경로 → 건너뛰고 사유를 요약에 누적(전체 중단 안 함)
   └─ 심볼릭/정션 링크 → 따라가지 않음/방문 집합으로 순환 차단(무한 재귀·중복 집계 없음)
→ 완료: 용량 상위 10개(폴더/파일) = 막대 차트 + 표, 여유 %·최대 폴더 인사이트 (※ 유형별 비중은 선택항 미구현)
→ Esc/닫기 → 탐색 화면 복귀
```

### F8. 블루라이트 차단 테마로 전환 (I2 ✅ 구현 완료 — `BLUELIGHT_PALETTE`·`ThemeMode` 4종·WCAG AA 통과)
```
설정(Ctrl+,) → 테마 → 라이트/다크/시스템/블루라이트 차단 중 "블루라이트 차단" 선택
→ 즉시 전체 화면 적용(배경 #FBF0D9 크림, 텍스트 WCAG AA 지향) → 설정/세션 영속(재시작 후 유지)
   ※ 아이콘바 테마 토글은 라이트↔다크 즉시 전환(기존)이며, 4종 선택은 설정에서 한다
```

### F9. 보기 모드 전환 · 드래그 박스 선택 (J3·J1 ✅)
```
[보기 전환] 아이콘바 보기 컨트롤 또는 우클릭 "보기" → 큰/보통/작은 아이콘·목록·자세히 5종 중 선택
            → 아이콘 그리드는 OS 실제 아이콘(shell:icon, H6) 크기 단계만 달리·가상 스크롤·패널별 기억
[박스 선택] 목록 빈 영역 드래그 → 러버밴드 사각형과 교차하는 항목 실시간 선택(놓으면 확정)
            ├─ Ctrl=누적 / Shift=범위 확장 / 수정키 없음=새 선택 교체
            └─ 목록 경계로 끌면 자동 스크롤(새로 보이는 항목도 포함) → 상태바에 개수·용량 반영
```

### F10. 패널 실시간 갱신 (J2 ✅ — fs:watch:*·WatchService·os/driveType.ts; UNC + 매핑 네트워크 드라이브 폴링 폴백 ✅)
```
패널이 폴더 열기 → 그 폴더에 워처 부착(fs:watch:start) → 외부에서 파일 생성/삭제/이름변경 발생
→ 워처 감지(디바운스로 묶음·fs:watch:event) → softRefresh로 목록 자동 반영(정렬·필터·선택·스크롤 보존 ✅)
   ├─ 대량 변경 → 디바운스 병합 1회 갱신(UI 비차단)
   ├─ 폴더 삭제·접근 불가/권한/네트워크/미지원 → 워처 정리(throw 0 격리)+패널 사유 표시(앱 중단 없음)
   ├─ 선택·스크롤 보존 ✅ → capturePreserve→_applyPreserve·pendingScrollRestore 1회성 복원(navigate 시엔 resetSelection으로 비움)
   ├─ UNC(\\서버\공유) ✅ → eager 폴링 폴백(4s readdir diff·stat 승계·>20k 비활성)
   ├─ 매핑 네트워크 드라이브(X:\) ✅ → GetDriveType 연동(os/driveType.ts PowerShell CIM DriveType=4→문자 캐시·paths.isNetworkDriveRoot)으로 eager 폴링 적용
   └─ 【잔여 한계】 subst·일부 클라우드 드라이브(DriveType≠4) → 미포함, reactive(fs.watch 실패 시) 폴백에만 의존·수동 새로고침 유지(런타임 매핑 변경 시 첫 진입 reactive→차순 eager)
패널 경로 이동 → 워처를 새 경로로 교체(fs:watch:stop·이전 경로 해제·누수 없음)
```

## 4. 반응형 / 레이아웃 규칙

- 창 폭이 좁아지면: 사이드바 자동 접힘 가능, 4분할은 최소 폭 미달 시 안내.
- 패널은 최소 가용 폭을 가지며, 미달 시 분할 추가를 막거나 경고.
- **분할선 드래그로 비율 조절(S, features §H3)**: 2분할=1축·4분할=가로/세로 2축. 최소 폭/높이 제약 이하로는 줄지 않으며, 분할선 더블클릭 시 균등 복귀. **조정 비율은 탭/레이아웃별로 세션 영속**(재시작 후 유지). MVP는 균등 분할.
- **사이드바 토글(S, features §H2)**: `Ctrl+B`/아이콘바 버튼으로 표시·숨김 전환, 숨김 시 패널 영역이 그 공간으로 확장. 토글 상태는 세션 영속.
- 미리보기 패널(S)은 패널 영역 우측 또는 하단에 토글로 부착. **(J6 ✅) 미리보기-본문 분할선 드래그로 폭 조절·세션 영속(`ui.previewWidth`·H3 메커니즘 재사용), (J5 ✅) 상하 2단(정보+뷰어: 이미지·텍스트·코드강조·마크다운).**
- **패널 실시간 갱신(S, features §J2 ✅)**: 각 패널이 자기 폴더를 워처로 감시해 디스크 변경을 자동 반영(`fs:watch:*`·디바운스·정렬/필터·선택/스크롤 보존·권한/삭제/네트워크 예외 격리·`softRefresh`). **UNC + 매핑 네트워크 드라이브(`X:\`) 폴링 폴백 ✅**(`GetDriveType` 연동: `os/driveType.ts` PowerShell CIM `DriveType=4`·`paths.isNetworkDriveRoot`). `subst`·일부 클라우드(`DriveType≠4`)만 미포함 한계.
- **사용량 대시보드(S, features §I1 ✅)** 는 메인 화면 위 모달 오버레이로 표시(부착형 아님·`DashboardModal`). 실행 시 자동 팝업은 설정 토글(기본 켜짐)로 제어하며, 모달 동안에도 백그라운드 스캔(`scanWorker`)은 비차단.
