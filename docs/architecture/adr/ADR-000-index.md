> **ADR-007은 ADR-005(프로세스/보안 모델)의 "네트워크 차단 기본·로컬 전용" 부분을 §M3(FTP/SFTP)에 한해 부분 개정한다**(삭제·대체 아님·비파괴). 상세는 ADR-007 결정 ①②.
> **ADR-008~012(2026-06-09 §P~§U 파워 기능 14종)** 는 기존 ADR/설계를 보존·승계하며 신규만 추가한다. archive(ADR-008)·해시(ADR-009)·grep(ADR-010)·전송 큐(ADR-011)는 ADR-005 프로세스/보안(렌더러 직접 FS/네트워크 금지·경로 검증·Zip Slip 차단)·ADR-003 throw0/Result·IPC guard를 전면 준수하고, **외부로 나가는 신규 네트워크/실행은 없다**(압축·grep·해시 전부 로컬). 경량 기능(⑥명령팔레트·⑧폴더용량·⑩퀵룩·⑪브레드크럼·⑫탭색상/잠금/분리)은 ADR 없이 software-architecture §14에 모듈 설계로 둔다.
> **ADR-013(2026-06-12 §Y Windows 셸 컨텍스트 메뉴 연동·단일+다중)** 도 ADR-005를 전면 준수한다(sender·zod(`paths` 배열)·guardPath(각 경로)·로컬 한정(원격/archive 혼입 거부)·**명령행 합성 0**=경로 배열을 stdin JSON으로만 전달·실행 표면 미추가=탐색기 단일·다중 우클릭과 동일 신뢰 모델). 신규 네이티브/npm 의존성 0(COM·PowerShell·.NET 컴파일러 시스템 내장 — 다중 `IContextMenu`도 C# `Add-Type` P/Invoke로 네이티브 빌드 없이 처리). **초기 1차는 단일 선택 한정이었으나 2026-06-12 다중 선택 지원으로 확장**(다중은 저수준 `IContextMenu` 경로 추가·기존 채널 `path`→`paths` 계약 확장·신규 채널 0). `showProperties`(COM `Verbs()`/`DoIt()`)·hash/grep 워커(수명·취소)·B6 컨텍스트 메뉴 인프라의 비파괴 확장이다. 상태 구현 완료(코드)·실 GUI 🟡.
> **ADR-014(2026-06-14 §Z 가칭 자연어 파일 에이전트·Agentic)** 는 ADR-005·ADR-007을 **삭제·대체하지 않고 비파괴 부분 확장**한다. ① 에이전트 루프를 **Main 단일 신뢰 경계**에 둬 ADR-005(렌더러 FS/네트워크 금지)·ADR-007 결정⑤(외부 네트워크·비밀 의존 작업=Main 스레드)를 그대로 따른다. ② BYO API 키는 **ADR-007 결정③ safeStorage(DPAPI) credentialStore 패턴을 재사용**(평문·렌더러 노출 0). ③ 네트워크는 **D7에 Anthropic 단일 엔드포인트 1건만 추가**(전면 개방 아님)하고 SDK import를 **`src/main/agent/`에만 ESLint 화이트리스트로 격리**(ADR-007 결정② 동형). ④ 도구는 명시 화이트리스트(읽기=즉시 실행/쓰기=plan 스테이징·미실행)·**실행은 기존 op:* + undoMeta 재사용**(휴지통·Ctrl+Z·신규 실행 표면 0)·파괴/원격/셸 도구 미노출이라 ADR-005 "실행 표면 미추가" 정신을 지킨다. 신규 npm `@anthropic-ai/sdk`(순수 JS·네이티브 0)·신규 채널 `agent:*` 6종(P1 동결 후 신기능 선례 동일 규약·동결 위반 아님)·`SESSION_SCHEMA_VERSION` 무변. **ADR-005·ADR-007 본문에 ADR-014 상호참조 메모 추가(은폐 금지).** 상태 🔜 설계 완료·구현 전 · ⚠️ **요구사항/스코프는 product-planner 확정 필요**(ADR-014 §스코프 게이트 SG-1~SG-6). 상세 컴포넌트·계약·데이터플로우는 [agent-natural-language-design.md](../agent-natural-language-design.md). **[2026-06-14 갱신] 사용자가 멀티 AI 제공자(Claude·OpenAI·내부 자체 모델)를 확정 → [ADR-015]가 ADR-014 결정 ②⑤⑧을 멀티 제공자로 일반화·일부 대체(비파괴)**: `LLMProvider` 추상화·function-calling 정규화·내부 SSRF·제공자별 키·D7→D8.
> **ADR-016(2026-06-14 §Z 에이전트 오케스트레이션 하이브리드·ToolCatalog)** 는 ADR-014·ADR-015를 **삭제·대체하지 않고 오케스트레이션 토폴로지만 비파괴 확장**한다(요구/스코프 무변경 — 동일 "읽기 전용 Q&A"의 내부 리팩터·product-planner 불요·사용자 직접 결정). ① ADR-014 결정 ④(tool-use 루프)의 **단일 ReAct → Plan-Execute + ReAct 하이브리드**(Planner가 `ReasoningPlan` 스텝 목록 산출 → Executor가 스텝별 ReAct 미니루프 → 실패·관찰·상한 시 Re-plan·단순 질의는 plan 우회=현 동작 동치). ⚠️ 본 ADR `ReasoningPlan`/`ReasoningStep`은 **추론 계획**으로 ADR-014 쓰기 `PlannedOp`(파일쓰기 변경안·plan-add/ready·diff)와 **완전 별개**(용어 분리). ② 도구를 **`ToolCatalog` 인터페이스**(발견 describe/실행 invoke/메타 mode)로 추상화 — 현 `toolRegistry`의 `TOOLS` 맵·`executeTool`이 `createDefaultToolCatalog` 구현체가 됨(읽기 전용·scope·is_error 1:1 보존·SDK/서비스 주입성 유지·헤드리스 verify 스텁 주입). ③ 모델 라우팅은 **기존 `modelRouter` 2-티어 그대로**(Planner=plan·Executor=light·제공자 무지·신규 티어/모델 0). ④ `AgentEvent`에 plan/step 변형 **비파괴 추가**(신규 IPC 채널 0·기존 변형 무변·패널 스텝 표시는 plan 있을 때만=점진적). ⑤ 상한 5종(`MAX_PLAN_STEPS`·`MAX_STEP_TURNS`·`MAX_STEP_TOOL_ERRORS`·`MAX_REPLANS`·`REPLAN_BUDGET_RATIO`) `limits.ts` 추가·전역 상한 우선. **읽기 전용·scope·SSRF·키 safeStorage·네이티브 0·`SESSION_SCHEMA_VERSION` 무변·쓰기 도구 0 전부 보존**(프롬프트 인젝션이 plan/실행을 오염시켜도 도구가 읽기/navigate뿐·scope가 흡수). 상태 🔜 설계 완료·구현 전. 상세는 [ADR-016](./ADR-016-hybrid-orchestration-and-toolcatalog.md)·[agent-natural-language-design.md §14·§15](../agent-natural-language-design.md).
> **ADR-015(2026-06-14 §Z1 멀티 LLM 제공자 추상화)** 는 ADR-014를 **삭제하지 않고 추상화 1겹을 끼워 확장**한다. ① `AgentOrchestrator`가 **`LLMProvider` 인터페이스 1개에만 의존**(제공자 무지) → 구현체 3종(Anthropic·OpenAI·내부 OpenAI 호환)이 SDK/엔드포인트/포맷 차이를 숨긴다. ② **function-calling 정규화 어댑터**가 Anthropic `tool_use` ↔ OpenAI `tool_calls`를 공통 도구 호출 표현으로 양방향 변환(JSON Schema 1벌·toolRegistry 단일 출처·깨진 arguments→is_error tool_result·throw 0). ③ **tool-use 미지원 모델은 명시 degradation**(capability+probe·자유텍스트 plan 폴백 비채택 — ADR-014 구조적 도구 호출 안전 유지). ④ **내부 base URL SSRF 다단계 방어**(화이트리스트 정확 일치 + IP 리터럴 사설/loopback/링크로컬/메타데이터 169.254.169.254 차단 + DNS 리바인딩/리다이렉트 + 요청 직전 Main 재검증). ⑤ 제공자별 키 **safeStorage 슬롯**(ADR-014 결정 ② 불변식 일반화·평문/렌더러/DTO 0)·`agent:provider:*`+`agent:key:*`(provider 인자) 채널(settings 확장 비채택=비밀 격리). ⑥ SDK `@anthropic-ai/sdk`+`openai`(둘 다 순수 JS·네이티브 0 전제·내부=openai SDK `baseURL` 재사용)·SDK/네트워크 import는 `src/main/agent/`에만 ESLint 격리(`verify:eslint-agent`·ADR-007 결정② 동형).
