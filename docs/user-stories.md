## 에픽 1. 멀티 디렉토리 동시 관리 (핵심 차별점)

### US-1.1 탭으로 여러 위치 보관 — M · 규모 M
파워유저로서, 자주 쓰는 폴더를 오가기 위해 여러 탭으로 위치를 보관하고 싶다.
- [ ] `Ctrl+T`/`+`로 새 탭이 열린다
- [ ] `Ctrl+W`/가운데클릭/X로 탭을 닫는다
- [ ] `Ctrl+Tab`/`Ctrl+1~9`/클릭으로 탭을 전환한다
- [ ] 드래그로 탭 순서를 바꾼다
- [ ] `Ctrl+D`/우클릭 메뉴로 현재 탭을 동일 경로로 복제한다
- [ ] `Ctrl+Shift+T`로 직전에 닫은 탭이 복원된다
- [ ] 마지막 탭을 닫으면 "내 PC"(드라이브 목록) 기본 탭이 유지된다(빈 화면 아님)
- [ ] 각 탭은 자신의 경로·정렬·보기·탐색 히스토리를 독립 유지한다

### US-1.2 화면을 2분할해 두 폴더 나란히 보기 — M · 규모 L
정리광 사용자로서, 출발·도착 폴더를 동시에 보기 위해 화면을 2개 패널로 나누고 싶다.
- [ ] 좌우 또는 상하 2분할을 선택할 수 있다
- [ ] 각 패널이 독립된 경로·목록·선택 상태를 가진다
- [ ] 활성 패널이 시각적으로(테두리/헤더) 구분된다
- [ ] `Tab`(또는 `Ctrl+←/→`)로 패널 포커스를 이동한다 *(파일 이동 키 `F6`과 분리됨)*
- [ ] 분할을 해제하면 단일 패널로 돌아간다
- [ ] 분할 구성은 탭마다 독립적이다

### US-1.3 패널 간 드래그로 파일 이동/복사 — M · 규모 L
사용자로서, 폴더 간 파일을 빠르게 옮기기 위해 한 패널에서 다른 패널로 드래그하고 싶다.
- [ ] 선택 항목을 다른 패널로 드래그&드롭하면 이동/복사된다
- [ ] 같은 드라이브=이동, 다른 드라이브=복사가 기본 동작이다
- [ ] 드래그 중 `Ctrl`=복사 강제, `Shift`=이동 강제가 적용된다
- [ ] 드래그 중 복사/이동 의도가 커서·툴팁으로 표시된다
- [ ] 드롭 가능한 대상이 하이라이트된다
- [ ] 폴더 항목 위에 드롭하면 그 폴더 안으로 들어간다
- [ ] ~~단축키 `F5`=다른 패널로 복사 / `F6`=다른 패널로 이동이 동작한다~~ — **삭제됨/Deprecated(2026-06-07 사용자 요청, 사유: 일반 사용자에게 일반적이지 않은 단축키). 패널 간 복사/이동은 D&D·클립보드(`Ctrl+C/X/V`)로 수행하며, 본 스토리의 D&D 수용 기준은 그대로 유지된다.** 새로고침은 기존대로 `Ctrl+R`
- [ ] 출발=도착 동일 폴더에 드롭하면 작업 없이 무시된다
- [ ] 조상 폴더를 그 자손으로 이동하려 하면 차단되고 안내 메시지가 뜬다

### US-1.4 4분할로 다중 폴더 동시 작업 — S · 규모 M · ✅ 완료(P6)
파워유저로서, 더 많은 폴더를 한 번에 다루기 위해 2x2 4분할을 쓰고 싶다.
- [ ] 2x2 레이아웃으로 분할된다
- [ ] 4개 패널 각각 독립 경로/상태를 가진다
- [ ] 패널 포커스 순환 이동이 된다

## 에픽 2. 파일/폴더 기본 조작

### US-2.1 목록 보기와 정렬 — M · 규모 M
사용자로서, 내용을 파악하기 위해 보기 방식과 정렬을 바꾸고 싶다.
- [ ] 상세(이름/크기/형식/수정일)·리스트 보기를 전환한다
- [ ] 컬럼 클릭으로 정렬 기준·방향을 바꾼다
- [ ] 이름 정렬에 자연 정렬(파일2<파일10)이 적용된다
- [ ] 폴더 우선 정렬이 기본 적용되고 토글 가능하다
- [ ] 보기/정렬 상태가 패널별로 기억된다

### US-2.2 생성·이름변경·삭제 — M · 규모 M
사용자로서, 폴더를 정리하기 위해 항목을 만들고 이름을 바꾸고 지우고 싶다.
- [ ] `Ctrl+Shift+N`으로 새 폴더가 생기고 즉시 이름 편집 상태가 된다
- [ ] `F2`로 이름을 변경하며, 금지문자·중복명은 차단·안내된다
- [ ] `Delete`로 휴지통으로 이동된다(되돌리기 가능)
- [ ] `Shift+Delete`는 확인 후 영구 삭제한다
- [ ] 실패(권한/사용중) 시 사유가 안내된다

### US-2.3 복사·잘라내기·붙여넣기 — M · 규모 M
사용자로서, 파일을 옮기기 위해 클립보드 작업을 하고 싶다.
- [ ] `Ctrl+C/X/V`가 동작하고 OS 클립보드와 호환된다
- [ ] 잘라내기 항목이 흐리게 표시되고 붙여넣기 전 원본이 유지된다
- [ ] 같은 폴더 붙여넣기 시 "복사본" 규칙으로 자동 명명된다
- [ ] 이름 충돌이 발생하면 US-2.4의 충돌 해결 흐름으로 연결된다

### US-2.4 복사/이동 충돌 해결 — M · 규모 M
사용자로서, 데이터를 안전하게 다루기 위해 같은 이름 대상이 있을 때 명시적으로 선택하고 싶다.
- [ ] 같은 이름 대상이 있으면 **명시적 확인 없이 임의 덮어쓰기가 일어나지 않는다**
- [ ] 충돌 다이얼로그에서 **덮어쓰기 / 건너뛰기 / 둘 다 유지** 중 선택할 수 있다
- [ ] **둘 다 유지** 선택 시 새 항목이 "이름 (n)"으로 명명되어 양쪽이 보존된다
- [ ] 같은 이름 **폴더**는 삭제·교체가 아니라 **병합**되며, 내부 동일명 파일만 다시 충돌 판정된다
- [ ] **모두 적용** 체크 시 이후 동일 유형 충돌에 같은 선택이 일괄 적용되어 다이얼로그가 재표시되지 않는다
- [ ] **읽기전용** 대상 덮어쓰기는 추가 확인 후 진행, 거부 시 건너뛴다
- [ ] **사용 중 / 권한 없는** 대상은 사유와 함께 자동 건너뛰고, 작업 종료 후 **실패 항목·사유 목록**이 요약된다
- [ ] 충돌 다이얼로그에 양쪽 항목의 **크기·수정일**이 비교 가능하게 표시된다

## 에픽 3. 탐색

### US-3.1 주소 표시줄과 이동 버튼으로 탐색 — M · 규모 M
사용자로서, 원하는 위치로 빠르게 가기 위해 주소 표시줄과 이동 버튼을 쓰고 싶다.
- [ ] 브레드크럼으로 경로가 표시되고 구간 클릭으로 이동한다
- [ ] `Ctrl+L`/클릭으로 경로를 직접 입력·붙여넣어 이동한다
- [ ] 잘못된 경로는 인라인 오류로 안내되고 이동하지 않는다
- [ ] `Alt+←/→/↑`로 뒤로/앞으로/위로 이동한다
- [ ] 경로 텍스트를 복사하는 액션이 있다

### US-3.2 트리 사이드바로 폴더 이동 — M · 규모 M
사용자로서, 전체 구조를 보며 이동하기 위해 좌측 트리를 쓰고 싶다.
- [ ] 드라이브/폴더 트리가 펼침·접힘된다
- [ ] 트리 항목 클릭 시 활성 패널 경로가 바뀐다
- [ ] 즐겨찾기/최근/휴지통/내 PC 섹션이 있다
- [ ] 사이드바를 토글·폭조절할 수 있다

### US-3.3 즐겨찾기와 최근 위치 — M · 규모 S
사용자로서, 자주/최근 위치에 빠르게 가기 위해 즐겨찾기·최근 목록을 쓰고 싶다.
- [ ] 폴더를 즐겨찾기에 추가/제거한다
- [ ] 즐겨찾기가 사이드바에 고정 표시된다
- [ ] 최근 방문 폴더가 자동 기록되어 접근 가능하다
- [ ] 최근 항목을 개별/전체 삭제할 수 있다

## 에픽 4. 검색 / 필터 / 미리보기

### US-4.1 현재 폴더 내 검색 — M · 규모 M

- [ ] 일치 부분이 하이라이트된다
- [ ] 검색을 해제하면 전체 목록으로 복귀한다

## 에픽 7. UX / 레이아웃 확장 (2026-06-07 편입)

> **[2026-06-07 추가 편입·구현 완료 ✅] US-7.4(터미널 열기)·US-7.5(경로 직접 입력)·US-7.6(파일 유형 아이콘)** 3종을 추가, team-dev에서 구현·QA PASS. US-7.4는 컨텍스트 메뉴·ADR-005 보안(신규 채널 `shell:open-terminal`), US-7.5는 C1 주소 표시줄·`validateAndNavigate`(단일 클릭 편집 진입), US-7.6은 P1 동결된 `shell:icon` 채널을 정식 구현(호출부 추가)하여 각각 재사용·구현했다. US-7.4(네이티브 `wt.exe`)·US-7.6(`app.getFileIcon`)의 실제 네이티브 실행은 런타임 스모크 권장(코드 정합 충족).

### US-7.1 상단 아이콘바로 빠르게 실행 — S · 규모 M · ✅ 완료
사용자로서, 자주 쓰는 기능을 마우스로 빠르게 실행하기 위해 상단 아이콘 버튼바를 쓰고 싶다.
- [x] 탭바 아래에 레이아웃/뷰·파일 작업·탐색·도구 4개 그룹이 구분선으로 나뉘어 표시된다(`iconBarItems.ts` 4그룹)
- [x] 각 버튼 클릭이 키보드 단축키와 동일한 commandId를 활성 패널에 실행한다(execCommand 수렴)
- [x] 컨텍스트상 불가능한 동작의 버튼은 비활성(흐림)되고 클릭해도 동작하지 않는다(activeWhen)
- [x] 토글형 버튼(사이드바·미리보기·테마·분할 모드·보기 모드)이 현재 상태를 시각적으로 반영한다(`aria-pressed`)
- [x] 버튼 툴팁에 동작명과 해당 단축키가 표시된다
- [x] 테마 토글 버튼이 라이트↔다크를 즉시 전환한다(`theme.toggle`→`toggleThemeMode`)

### US-7.2 사이드바를 접어 화면 넓게 쓰기 — S · 규모 S · ✅ 완료 (※ 실제 토글은 런타임 스모크 권장)
사용자로서, 패널을 넓게 쓰기 위해 좌측 사이드바를 접고 펴고 싶다.
- [x] `Ctrl+B` 또는 아이콘바 버튼으로 사이드바가 표시↔숨김 전환된다(`sidebar.toggle`→`toggleSidebar`)
- [x] 사이드바를 숨기면 패널 영역이 그 공간으로 확장된다
- [x] 토글 상태가 세션에 저장되어 재시작 후 마지막 상태로 복원된다(기존 `sidebarCollapsed` 영속)
- [x] 아이콘바 버튼이 현재 표시/숨김 상태를 시각적으로 반영한다(`aria-pressed`)

### US-7.3 분할 패널 비율 조절 — S · 규모 M · ✅ 완료 (※ 실제 드래그는 런타임 스모크 권장)
사용자로서, 작업에 맞게 화면을 배분하기 위해 분할 패널의 비율을 조절하고 싶다.

### US-7.4 우클릭으로 현재 폴더에서 터미널 열기 — S · 규모 S · ✅ 완료 (※ 네이티브 `wt.exe` 실행은 런타임 스모크 권장)

- [x] 패널 빈 영역 우클릭의 "터미널 열기"는 현재 패널 경로를 작업 디렉토리로 연다
- [x] Windows Terminal(`wt.exe -d`)이 있으면 그것으로, 없으면 `powershell.exe -NoExit`로 폴백해 열린다(`os/shell.ts#openTerminal`)
- [x] 파일 항목·드라이브 목록(내 PC)에는 "터미널 열기"가 비활성 또는 미표시된다
- [x] 경로 검증(정규화·`..` 이탈 차단·존재·stat 디렉토리 검증)을 통과하지 못한 경로는 터미널을 실행하지 않고 사유가 안내된다(`shell.handlers.ts`·ADR-005)
- [x] 경로가 `execFile` 인자 배열로 전달되어 셸 메타문자가 포함된 폴더명에도 명령 주입이 발생하지 않는다(셸 경유 없음)

- [x] 기존 `Ctrl+L`·더블클릭으로도 동일하게 편집 모드에 진입한다
- [x] Enter로 입력 경로로 이동하고, Esc로 편집을 취소해 원래 표시로 복귀한다
- [x] 잘못된/존재하지 않는 경로는 인라인 오류로 안내되고 이동하지 않으며 편집 모드가 유지된다(`validateAndNavigate` 재사용)
- [x] 클립보드 경로를 붙여넣어 Enter로 즉시 이동할 수 있다
- [x] 입력은 활성 패널 경로만 변경한다(다른 패널·탭에 영향 없음)
