## 에픽 1. 멀티 디렉토리 동시 관리 (핵심 차별점)

### US-1.1 탭으로 여러 위치 보관 — M · 규모 M
파워유저로서, 자주 쓰는 폴더를 오가기 위해 여러 탭으로 위치를 보관하고 싶다.
- [ ] `Ctrl+T`/`+`로 새 탭이 열린다
- [ ] `Ctrl+W`/가운데클릭/X로 탭을 닫는다
- [ ] `Ctrl+Tab`/`Ctrl+1~9`/클릭으로 탭을 전환한다
- [ ] 드래그로 탭 순서를 바꾼다
- [ ] `Ctrl+D`/우클릭 메뉴로 현재 탭을 동일 경로로 복제한다
- [ ] `Ctrl+Shift+T`로 직전에 닫은 탭이 복원된다
- [ ] 마지막 탭을 닫으면 "내 PC"(드라이브 목록) 기본 탭이 유지된다(빈 화면 아님)
- [ ] 각 탭은 자신의 경로·정렬·보기·탐색 히스토리를 독립 유지한다

### US-1.2 화면을 2분할해 두 폴더 나란히 보기 — M · 규모 L
정리광 사용자로서, 출발·도착 폴더를 동시에 보기 위해 화면을 2개 패널로 나누고 싶다.
- [ ] 좌우 또는 상하 2분할을 선택할 수 있다
- [ ] 각 패널이 독립된 경로·목록·선택 상태를 가진다
- [ ] 활성 패널이 시각적으로(테두리/헤더) 구분된다
- [ ] `Tab`(또는 `Ctrl+←/→`)로 패널 포커스를 이동한다 *(파일 이동 키 `F6`과 분리됨)*
- [ ] 분할을 해제하면 단일 패널로 돌아간다
- [ ] 분할 구성은 탭마다 독립적이다

### US-1.3 패널 간 드래그로 파일 이동/복사 — M · 규모 L
사용자로서, 폴더 간 파일을 빠르게 옮기기 위해 한 패널에서 다른 패널로 드래그하고 싶다.
- [ ] 선택 항목을 다른 패널로 드래그&드롭하면 이동/복사된다
- [ ] 같은 드라이브=이동, 다른 드라이브=복사가 기본 동작이다
- [ ] 드래그 중 `Ctrl`=복사 강제, `Shift`=이동 강제가 적용된다
- [ ] 드래그 중 복사/이동 의도가 커서·툴팁으로 표시된다
- [ ] 드롭 가능한 대상이 하이라이트된다
- [ ] 폴더 항목 위에 드롭하면 그 폴더 안으로 들어간다
- [ ] 단축키 `F5`=다른 패널로 복사 / `F6`=다른 패널로 이동이 동작한다(새로고침 `Ctrl+R`과 충돌 없음)
- [ ] 출발=도착 동일 폴더에 드롭하면 작업 없이 무시된다
- [ ] 조상 폴더를 그 자손으로 이동하려 하면 차단되고 안내 메시지가 뜬다

### US-1.4 4분할로 다중 폴더 동시 작업 — S · 규모 M · ✅ 완료(P6)
파워유저로서, 더 많은 폴더를 한 번에 다루기 위해 2x2 4분할을 쓰고 싶다.
- [ ] 2x2 레이아웃으로 분할된다
- [ ] 4개 패널 각각 독립 경로/상태를 가진다
- [ ] 패널 포커스 순환 이동이 된다

## 에픽 2. 파일/폴더 기본 조작

### US-2.1 목록 보기와 정렬 — M · 규모 M
사용자로서, 내용을 파악하기 위해 보기 방식과 정렬을 바꾸고 싶다.
- [ ] 상세(이름/크기/형식/수정일)·리스트 보기를 전환한다
- [ ] 컬럼 클릭으로 정렬 기준·방향을 바꾼다
- [ ] 이름 정렬에 자연 정렬(파일2<파일10)이 적용된다
- [ ] 폴더 우선 정렬이 기본 적용되고 토글 가능하다
- [ ] 보기/정렬 상태가 패널별로 기억된다

### US-2.2 생성·이름변경·삭제 — M · 규모 M
사용자로서, 폴더를 정리하기 위해 항목을 만들고 이름을 바꾸고 지우고 싶다.
- [ ] `Ctrl+Shift+N`으로 새 폴더가 생기고 즉시 이름 편집 상태가 된다
- [ ] `F2`로 이름을 변경하며, 금지문자·중복명은 차단·안내된다
- [ ] `Delete`로 휴지통으로 이동된다(되돌리기 가능)
- [ ] `Shift+Delete`는 확인 후 영구 삭제한다
- [ ] 실패(권한/사용중) 시 사유가 안내된다

### US-2.3 복사·잘라내기·붙여넣기 — M · 규모 M
사용자로서, 파일을 옮기기 위해 클립보드 작업을 하고 싶다.
- [ ] `Ctrl+C/X/V`가 동작하고 OS 클립보드와 호환된다
- [ ] 잘라내기 항목이 흐리게 표시되고 붙여넣기 전 원본이 유지된다
- [ ] 같은 폴더 붙여넣기 시 "복사본" 규칙으로 자동 명명된다
- [ ] 이름 충돌이 발생하면 US-2.4의 충돌 해결 흐름으로 연결된다

### US-2.4 복사/이동 충돌 해결 — M · 규모 M
사용자로서, 데이터를 안전하게 다루기 위해 같은 이름 대상이 있을 때 명시적으로 선택하고 싶다.
- [ ] 같은 이름 대상이 있으면 **명시적 확인 없이 임의 덮어쓰기가 일어나지 않는다**
- [ ] 충돌 다이얼로그에서 **덮어쓰기 / 건너뛰기 / 둘 다 유지** 중 선택할 수 있다
- [ ] **둘 다 유지** 선택 시 새 항목이 "이름 (n)"으로 명명되어 양쪽이 보존된다
- [ ] 같은 이름 **폴더**는 삭제·교체가 아니라 **병합**되며, 내부 동일명 파일만 다시 충돌 판정된다
- [ ] **모두 적용** 체크 시 이후 동일 유형 충돌에 같은 선택이 일괄 적용되어 다이얼로그가 재표시되지 않는다
- [ ] **읽기전용** 대상 덮어쓰기는 추가 확인 후 진행, 거부 시 건너뛴다
- [ ] **사용 중 / 권한 없는** 대상은 사유와 함께 자동 건너뛰고, 작업 종료 후 **실패 항목·사유 목록**이 요약된다
- [ ] 충돌 다이얼로그에 양쪽 항목의 **크기·수정일**이 비교 가능하게 표시된다

## 에픽 3. 탐색

### US-3.1 주소 표시줄과 이동 버튼으로 탐색 — M · 규모 M
사용자로서, 원하는 위치로 빠르게 가기 위해 주소 표시줄과 이동 버튼을 쓰고 싶다.
- [ ] 브레드크럼으로 경로가 표시되고 구간 클릭으로 이동한다
- [ ] `Ctrl+L`/클릭으로 경로를 직접 입력·붙여넣어 이동한다
- [ ] 잘못된 경로는 인라인 오류로 안내되고 이동하지 않는다
- [ ] `Alt+←/→/↑`로 뒤로/앞으로/위로 이동한다
- [ ] 경로 텍스트를 복사하는 액션이 있다

### US-3.2 트리 사이드바로 폴더 이동 — M · 규모 M
사용자로서, 전체 구조를 보며 이동하기 위해 좌측 트리를 쓰고 싶다.
- [ ] 드라이브/폴더 트리가 펼침·접힘된다
- [ ] 트리 항목 클릭 시 활성 패널 경로가 바뀐다
- [ ] 즐겨찾기/최근/휴지통/내 PC 섹션이 있다
- [ ] 사이드바를 토글·폭조절할 수 있다

### US-3.3 즐겨찾기와 최근 위치 — M · 규모 S
사용자로서, 자주/최근 위치에 빠르게 가기 위해 즐겨찾기·최근 목록을 쓰고 싶다.
- [ ] 폴더를 즐겨찾기에 추가/제거한다
- [ ] 즐겨찾기가 사이드바에 고정 표시된다
- [ ] 최근 방문 폴더가 자동 기록되어 접근 가능하다
- [ ] 최근 항목을 개별/전체 삭제할 수 있다

## 에픽 4. 검색 / 필터 / 미리보기

### US-4.1 현재 폴더 내 검색 — M · 규모 M
사용자로서, 많은 파일에서 원하는 것을 찾기 위해 이름으로 검색하고 싶다.
- [ ] `Ctrl+F`로 검색창이 열린다
- [ ] 입력 키 입력 후 **200ms 이내**에 목록이 점증 필터링되어 반영된다
- [ ] 일치 부분이 하이라이트된다
- [ ] 검색을 해제하면 전체 목록으로 복귀한다

### US-4.2 확장자/이름 필터 — M · 규모 S
사용자로서, 특정 유형만 보기 위해 패턴으로 필터링하고 싶다.
- [ ] `*.png`, `report*` 같은 패턴 필터가 적용된다
- [ ] 필터 결과 개수가 상태바에 반영된다

### US-4.3 선택 항목 미리보기 — S · 규모 M · ✅ 완료(P6)
사용자로서, 파일을 열지 않고 확인하기 위해 미리보기 패널을 보고 싶다.
- [ ] 이미지는 축소 미리보기가 표시된다
- [ ] 텍스트는 앞부분이 표시된다
- [ ] 기본 메타(크기/수정일/형식)가 표시된다
- [ ] 미지원 형식은 메타+아이콘만 표시된다

## 에픽 5. 부가 / 품질

### US-5.1 다중 선택과 일괄 작업 — M · 규모 M
사용자로서, 여러 파일을 한 번에 처리하기 위해 다중 선택하고 싶다.
- [ ] `Ctrl`/`Shift`/박스 선택/`Ctrl+A`가 동작한다
- [ ] 선택 항목에 복사/이동/삭제가 일괄 적용된다
- [ ] 선택 개수·합계 용량이 상태바에 표시된다

### US-5.2 대용량 복사 진행률과 취소 — M · 규모 M
사용자로서, 오래 걸리는 작업의 상태를 알기 위해 진행률을 보고 취소하고 싶다.
- [ ] 현재 파일명·전체 진행률·남은 항목/용량이 표시된다
- [ ] **진행률 표시가 200ms 이내 간격으로 갱신된다**(PRD 성능 목표)
- [ ] 작업 중 취소가 가능하며, 취소 시 진행분까지 처리하고 결과를 요약한다
- [ ] 작업 중에도 다른 탐색이 가능하다(UI 비차단 — 작업 진행 중 다른 탭/패널 조작이 멈추지 않는다)
- [ ] 부분 성공 시 실패 항목·사유 목록이 요약 보고된다

### US-5.6 대용량 폴더 빠른 첫 렌더 (성능) — M · 규모 M · 🟡 구현됨(실측 P7)
사용자로서, 큰 폴더도 기다림 없이 보기 위해 첫 화면이 빠르게 뜨길 원한다.
- [ ] **10,000개 항목 폴더의 첫 화면이 1.5초 이내**에 렌더된다(스피너→첫 화면, PRD 3장·7장)
- [ ] 가상 스크롤로 항목이 증분 표시되며, 로딩 중에도 UI가 멈추지 않는다
- [ ] 디렉토리 읽기는 백그라운드 처리되어 다른 패널/탭 조작을 막지 않는다
- [x] **[2026-06-07 결함 수정 ✅]** 뷰포트 높이 측정이 콜백 ref 기반 ResizeObserver로 동작해, 로딩 중 컨테이너 미마운트로 viewportH가 400px에 고정되던 결함이 없다(가시 항목 수가 실제 컨테이너 크기에 정확히 반영됨). 상세 features §G3.

### US-5.3 다크/라이트 테마 — M · 규모 S
사용자로서, 환경에 맞추기 위해 테마를 바꾸고 싶다.
- [ ] 라이트/다크/시스템 따름을 선택한다
- [ ] 변경이 즉시 적용된다

### US-5.4 키보드 중심 워크플로 — M · 규모 M
파워유저로서, 손을 키보드에 두기 위해 핵심 동작을 단축키로 하고 싶다.
- [ ] 탭/패널/탐색/파일조작/선택 핵심 동작에 단축키가 있다([PRD 8장](./PRD.md#8-단축키-체계-확정--충돌-없음) 표 전체)
- [ ] 포커스 이동(`Tab`)·복사(`F5`)·이동(`F6`)·새로고침(`Ctrl+R`)이 충돌 없이 각각 동작한다
- [ ] 단축키 목록을 설정/도움말에서 확인할 수 있다

### US-5.5 자동 세션 복원 — M · 규모 M
사용자로서, 작업을 이어가기 위해 종료 시 탭/패널이 자동 복원되길 원한다.
- [ ] 정상 재시작 시 마지막 탭 목록·경로·레이아웃이 복원된다
- [ ] 비정상 종료(크래시 등) 후 재실행 시에도 복원된다
- [ ] 각 패널의 경로·정렬·보기 상태도 함께 복원된다

### US-5.7 상태바 정보 표시 — M · 규모 S
사용자로서, 현재 상황을 빠르게 파악하기 위해 하단 상태바를 보고 싶다.
- [ ] 현재 폴더의 **전체 항목 수**가 표시된다
- [ ] **선택 개수**와 **선택 항목 합계 용량**이 표시된다
- [ ] **활성 패널의 현재 경로**가 요약 표시된다
- [ ] 검색/필터 적용 시 **필터된 결과 개수**로 갱신된다(US-4.2 연계)

### US-5.8 명시적 워크스페이스 저장/복원 — S · 규모 M · ✅ 완료(P6)
파워유저로서, 작업 세트를 재사용하기 위해 탭/패널 구성을 이름 붙여 저장하고 싶다.
- [ ] 현재 탭/패널 구성을 이름을 붙여 워크스페이스로 저장한다
- [ ] 저장한 워크스페이스를 선택해 불러오면 탭·패널·경로가 복원된다
- [ ] 워크스페이스를 이름변경/삭제할 수 있다

## 에픽 6. 릴리스 / 브랜딩 / 개발 도구 (DevEx)

> 사용자 화면 기능이 아닌 **릴리스 준비·브랜딩·개발 도구** 가치를 다루는 스토리다.
> 로드맵 외로 진행됐던 추가물을 **사후 정식 편입**한 것으로(roadmap §0.5 → 정식화), 모두 구현 완료(✅). 상세 규칙은 features §G.

### US-6.1 앱이 고유 아이콘으로 식별되기 — M(릴리스 요건) · 규모 S · ✅ 완료
사용자로서, 설치한 앱을 작업표시줄·시작 메뉴·실행 파일에서 한눈에 알아보기 위해 Explorer가 고유 아이콘으로 표시되길 원한다.
- [x] 인스톨러·실행 파일에 앱 아이콘이 적용된다(electron-builder `win.icon` → `resources/icon.ico` 멀티 사이즈)
- [x] 개발 실행 창에도 동일 아이콘이 적용된다
- [x] 아이콘 자산을 `scripts/gen-icon.ps1`로 생성·재현할 수 있다(`icon.ico`/`icon.png`)
- [x] 디자인이 제품 정체성(겹친 폴더·따뜻한 톤)을 반영한다

### US-6.2 한 번에 인스톨러 빌드하기 — 개발 도구(DevEx) · 규모 S · ✅ 완료
개발자로서, 릴리스 인스톨러를 빠르고 재현성 있게 만들기 위해 단일 명령으로 빌드 전 과정을 실행하고 싶다.
- [x] 루트 `build-installer.ps1` 하나로 의존성 점검 → typecheck → electron-vite build → electron-builder(NSIS)가 순차 실행된다
- [x] 완료 시 생성된 인스톨러 파일 경로가 출력된다
- [x] 중간 단계 실패 시 빌드가 중단되어 문제를 알 수 있다

## 에픽 7. UX / 레이아웃 확장 (2026-06-07 편입)

> 기존 동작을 더 빠르고 직관적으로 호출·조정하게 하는 UX 개선 스토리다. 모두 **S(Should)**.
> 상세 규칙은 [features §H](./features.md). 단축키는 [PRD 8장](./PRD.md#8-단축키-체계-확정--충돌-없음). 범례: ✅ 완료 · 🟡 부분 · 🔜 미착수.

### US-7.1 상단 아이콘바로 빠르게 실행 — S · 규모 M · ✅ 완료
사용자로서, 자주 쓰는 기능을 마우스로 빠르게 실행하기 위해 상단 아이콘 버튼바를 쓰고 싶다.
- [x] 탭바 아래에 레이아웃/뷰·파일 작업·탐색·도구 4개 그룹이 구분선으로 나뉘어 표시된다(`iconBarItems.ts` 4그룹)
- [x] 각 버튼 클릭이 키보드 단축키와 동일한 commandId를 활성 패널에 실행한다(execCommand 수렴)
- [x] 컨텍스트상 불가능한 동작의 버튼은 비활성(흐림)되고 클릭해도 동작하지 않는다(activeWhen)
- [x] 토글형 버튼(사이드바·미리보기·테마·분할 모드·보기 모드)이 현재 상태를 시각적으로 반영한다(`aria-pressed`)
- [x] 버튼 툴팁에 동작명과 해당 단축키가 표시된다
- [x] 테마 토글 버튼이 라이트↔다크를 즉시 전환한다(`theme.toggle`→`toggleThemeMode`)

### US-7.2 사이드바를 접어 화면 넓게 쓰기 — S · 규모 S · ✅ 완료 (※ 실제 토글은 런타임 스모크 권장)
사용자로서, 패널을 넓게 쓰기 위해 좌측 사이드바를 접고 펴고 싶다.
- [x] `Ctrl+B` 또는 아이콘바 버튼으로 사이드바가 표시↔숨김 전환된다(`sidebar.toggle`→`toggleSidebar`)
- [x] 사이드바를 숨기면 패널 영역이 그 공간으로 확장된다
- [x] 토글 상태가 세션에 저장되어 재시작 후 마지막 상태로 복원된다(기존 `sidebarCollapsed` 영속)
- [x] 아이콘바 버튼이 현재 표시/숨김 상태를 시각적으로 반영한다(`aria-pressed`)

### US-7.3 분할 패널 비율 조절 — S · 규모 M · ✅ 완료 (※ 실제 드래그는 런타임 스모크 권장)
사용자로서, 작업에 맞게 화면을 배분하기 위해 분할 패널의 비율을 조절하고 싶다.
- [x] 2분할에서 분할선을 드래그해 두 패널 비율을 실시간 조절한다(`ratioFromPoint`)
- [x] 4분할에서 가로·세로 분할선을 각각 드래그해 행·열 비율을 조절한다(grid 2축 독립)
- [x] 각 패널이 최소 폭/높이 제약 이하로 줄어들지 않는다(클램프 0.15~0.85)
- [x] 분할선 더블클릭 시 해당 축이 균등 비율로 복귀한다
- [x] 조정한 분할 비율이 세션에 저장되어 재시작 후에도 유지된다(`TabSnapshot.splitRatios`·`coerceSplitRatios`, 탭/레이아웃별 독립)
